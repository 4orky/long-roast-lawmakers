One satirical sentence roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF. The program writes one line to `/output/entry.txt`:

> They write the laws for AI, crypto and the internet, then print the email, sign the printout, scan it back in and call IT because the PDF they just made is somehow a photograph of their desk.

## Run it

```sh
python3 main.py
```
