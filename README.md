A single satirical sentence for the make.fun bounty of the same name: lawmakers ready to write the rules for AI, crypto and the internet, yet unable to turn a file into a PDF. The entry is picked by `main.py`, which drafts a slate of one-liners, grades each on subject, reversal, targeting, readability and surprise, and keeps the strongest.

They write the laws for AI, crypto and the internet, then print the email, sign the printout, scan it back in and call IT because the PDF they just made is somehow a photograph of their desk.

## How to run

Run `python3 main.py` from this directory; it writes the winning sentence to `/output/entry.txt` and prints it. The choice is deterministic, so every run produces the same file.

## Why this line wins

It opens with the lawmakers' authority, then undercuts it with a chain of small, specific humiliations — print, sign, scan, call IT — and lands on a photograph of a desk where a PDF should be. The joke stays on competence and power, never drifts into random abuse, and reads clean in one breath.
